# Двухслойная нейросеть на NumPy

**Python · NumPy · backpropagation**

Реализация прямого и обратного прохода двухслойной нейросети без фреймворка автоматического дифференцирования. Демонстрационная задача — XOR второго и четвёртого битов четырёхмерного входа.

```bash
python3 xor_demo.py --iterations 4000
python3 -m pytest -q
```

В коде выделены sigmoid, добавление смещения, train и predict. Производные вычисляются явно, используются матричные операции NumPy и фиксированный seed. Демонстрация проверяет обучение на полной таблице истинности.

В notebooks находится дополнительное упражнение по дифференцированию. Реализация предназначена для изучения связи математических формул и программного кода.
